What this is

Shadowbane shut down in 2009. EbonReach runs the same game on the MagicBane emulator, on a server that gets worked on rather than left alone — restored content that shipped broken, fixes for bugs the original never got round to, and rates set so two people can actually reach the part of the game worth playing.

It is not a nostalgia museum and it is not a rework. It is Shadowbane, with the sharp edges that were mistakes filed off and the sharp edges that were the point left exactly where they are.

How the world works

Cities are built, not chosen

Plant a Tree of Life, raise walls, hire NPCs, run mines. Everything on the map belongs to somebody who put it there.

Sieges are declared in the open

Place a bane, name the hour, and turn up. No matchmaking, no instance, no undo. The kill feed and siege log post to Discord as it happens.

Death costs something

Open-world PvP nearly everywhere. You drop what you were carrying and someone else picks it up.

Builds are yours to ruin

Six races, twelve promotion classes, discipline runes and trait points. Plenty of ways to build something excellent, and more ways to build something useless.

Starting out

  1. Download the launcher Windows only. It fetches the game files and keeps them current — about 2.3 GB the first time, a few seconds after that.
  2. Let it install Point it at an empty folder and leave it. When the button says Play, it is done.
  3. Pick a name and log in Your account is created the first time you log in. There is no separate signup and no email.
  4. Say hello on Discord The population is small enough that someone will notice you and help. discord.gg/PKH2wEC775
